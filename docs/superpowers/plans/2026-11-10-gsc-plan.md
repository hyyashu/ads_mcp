## 2. Shared pieces (`src/platforms/gsc/`)

### 2.1 `tools/common.ts` additions (foundation creates the file with `gscRead`/`gscWrite`)
```ts
export const PT = "America/Los_Angeles";
export const accountId = z.string().min(1).describe("Search Console site: the account_id from list_accounts or the property itself (https://example.com/ or sc-domain:example.com).");
export const ymd = z.string().regex(/^\d{4}-\d{2}-\d{2}$/).refine(isRealDate, "not a real date"); // reuse google/gaql isRealDate
export const SEARCH_TYPES = ["web", "image", "video", "news", "discover", "googleNews"] as const;
export const DIMENSIONS = ["country", "device", "page", "query", "searchAppearance", "date", "hour"] as const;
export const FILTER_DIMENSIONS = ["country", "device", "page", "query", "searchAppearance"] as const;
export const OPERATORS = ["equals", "notEquals", "contains", "notContains", "includingRegex", "excludingRegex"] as const;
export const AGGREGATIONS = ["auto", "byPage", "byProperty", "byNewsShowcasePanel"] as const;
export const DATA_STATES = ["final", "all", "hourly_all"] as const;
export const PERIODS = ["last_7_days", "last_28_days", "last_90_days", "last_180_days", "last_365_days", "last_16_months"] as const;

export const filterSchema = z.object({
  dimension: z.enum(FILTER_DIMENSIONS),
  operator: z.enum(OPERATORS).default("equals"),
  expression: z.string().min(1).max(4096),
}).superRefine(...) // country: /^[A-Za-z]{3}$/ unless regex operator; device with equals/notEquals: DESKTOP|MOBILE|TABLET (case-insensitive input, sent upper-case)

export const periodFields = {
  period: z.enum(PERIODS).default("last_28_days").describe("Named period ending on the latest day with data, in Pacific Time."),
  start_date: ymd.optional().describe("YYYY-MM-DD, Pacific Time. With end_date; overrides period."),
  end_date: ymd.optional(),
};
```

Helpers (pure, unit-tested):
- `pacificToday(now = new Date()): string` via `Intl.DateTimeFormat("en-CA", { timeZone: PT })`.
- `addDays(ymd, n)`, `minusMonths(ymd, 16)`.
- `oldestAllowed(today) = minusMonths(today, 16)` (F25).
- `checkDates(start, end, today)`: start ≤ end; end ≤ today; start ≥ oldestAllowed → else `invalid_argument` ("Search Console keeps 16 months of data; the earliest date available is …").
- `latestDataDate(gsc, type)`: one query `{startDate: today-10, endDate: today, dimensions: ["date"], type, dataState: "final", rowLimit: 11}` (F24); returns the max `keys[0]` or null.
- `resolvePeriod(gsc, args, type)`: explicit dates → validated as given; preset → end = `latestDataDate` (or `today-3` if the probe returned nothing, with a note), start = end − (days−1) (`last_16_months`: start = oldestAllowed). Returns `{ start_date, end_date, time_zone: PT, end_basis: "explicit" | "latest_final_data" | "fallback_today_minus_3" }`.
- `validateQuery(body)`: enforces F5, F12, F19, F22 and hour→hourly_all (see 4.2) before any call.
- `rowObject(dimensions, keys)`: `{ [dimension]: keys[i] }`.
- `metrics(row)`: `{clicks, impressions, ctr, position}` with `ctr` rounded to 4 dp, `position` rounded to 2 dp, `position` null when absent.
- `num(v)`: number from number or numeric string (U7), else null.
- `withinProperty(siteUrl, url)`: URL-prefix → `url.startsWith(siteUrl)`; `sc-domain:d` → URL host equals `d` or ends with `.d`, scheme http/https.
- `siteUrlSchema` (for add): `sc-domain:` + `/^[a-z0-9-]+(\.[a-z0-9-]+)+$/i` OR `https?://host[:port]/path/` ending with `/` (F37), max 2048, no whitespace. Never normalise silently: missing trailing slash → `invalid_argument` naming the fixed value.

### 2.2 Output building blocks
```ts
const Metrics = z.object({ clicks: z.number(), impressions: z.number(), ctr: z.number().nullable(), position: z.number().nullable() });
const Period = z.object({ start_date: z.string(), end_date: z.string(), time_zone: z.literal("America/Los_Angeles"), end_basis: z.enum(["explicit", "latest_final_data", "fallback_today_minus_3"]) });
```

## 3. Client methods to add to `GscClient` (`src/platforms/gsc/client.ts`)

`GscClient extends GoogleApiClient` and knows `siteUrl` (the connected account's external id). All URLs built with `encodeURIComponent` for `siteUrl` (F1) and `feedpath` (U4, inferred).

```ts
const WM = "https://www.googleapis.com/webmasters/v3";
const INSPECT = "https://searchconsole.googleapis.com/v1/urlInspection/index:inspect";

export type GscPermission = "siteFullUser" | "siteOwner" | "siteRestrictedUser" | "siteUnverifiedUser" | string;
export interface GscSite { siteUrl: string; permissionLevel: GscPermission }
export interface SaFilter { dimension: string; operator: string; expression: string }
export interface SaRequest {
  startDate: string; endDate: string; dimensions?: string[]; type?: string;
  dimensionFilterGroups?: { groupType: "and"; filters: SaFilter[] }[];
  aggregationType?: string; dataState?: string; // rowLimit/startRow are set by the client
}
export interface SaRow { keys?: string[]; clicks: number; impressions: number; ctr?: number; position?: number }
export interface SaResult { rows: SaRow[]; responseAggregationType: string | null; firstIncompleteDate: string | null; firstIncompleteHour: string | null; truncated: boolean }
export interface WmxSitemap { path: string; lastSubmitted?: string; isPending?: boolean; isSitemapsIndex?: boolean; type?: string; lastDownloaded?: string; warnings?: string | number; errors?: string | number; contents?: { type?: string; submitted?: string | number }[] }

class GscClient {
  get siteUrl(): string;
  private sitePath(site = this.siteUrl) { return `${WM}/sites/${encodeURIComponent(site)}`; }

  // Connection-wide (the Google user's whole property list)
  listSites(): Promise<GscSite[]>;                                   // read GET {WM}/sites → siteEntry ?? []
  findSite(siteUrl: string): Promise<GscSite | null>;               // listSites() then exact string match (never sites.get on a foreign url: avoids 403-vs-404 ambiguity)
  addSite(siteUrl: string): Promise<void>;                          // send("PUT", sitePath(siteUrl)) no body
  // This site
  getSite(): Promise<GscSite>;                                      // read GET sitePath()
  deleteSite(): Promise<void>;                                      // send("DELETE", sitePath())

  /**
   * Pages with startRow (F13). Per request rowLimit = min(25_000, maxRows + 1 - have). Stops at an empty page or when
   * have > maxRows. truncated = have > maxRows; rows sliced to maxRows. Past maxRows and !partial → ToolError("unsupported",
   * …, { details: { reason: "row_cap", max_rows } }) per PR #18. metadata/responseAggregationType taken from the first page.
   * Every request is idempotent (query()).
   */
  searchAnalytics(req: SaRequest, o: { maxRows: number; startRow?: number; partial?: boolean }): Promise<SaResult>;

  listSitemaps(sitemapIndex?: string): Promise<WmxSitemap[]>;      // read GET sitePath()/sitemaps[?sitemapIndex=] → sitemap ?? []
  getSitemap(feedpath: string): Promise<WmxSitemap | null>;         // read GET …/sitemaps/{enc}; not_found → null
  submitSitemap(feedpath: string): Promise<void>;                   // send("PUT", …/sitemaps/{enc}) no body
  deleteSitemap(feedpath: string): Promise<void>;                   // send("DELETE", …/sitemaps/{enc}) no body

  inspectUrl(inspectionUrl: string, languageCode?: string): Promise<Record<string, unknown>>; // query(INSPECT, {inspectionUrl, siteUrl, languageCode?}) → inspectionResult ?? {}
}
```

Notes for the client:
- `send` with no body must send no body (F34, F35, F39 say "do not supply a request body"). Check the foundation's `send` does not send `"{}"` or `null`; if it does, ask the foundation builder for a body-less path rather than working around it.
- `searchAnalytics` hard ceiling: `maxRows ≤ 50_000` (F18: more cannot exist for one day per type); throw `internal` above it.
- Error mapping is the foundation's (`gapi/http.ts`). The GSC builder checks, with tests, that the 403 reasons in F31 `quotaExceeded`, `rateLimitExceeded`, `userRateLimitExceeded`, `dailyLimitExceeded`, `limitExceeded`, `concurrentLimitExceeded`, `servingLimitExceeded` become `quota_exceeded`, and `forbidden`, `insufficientPermissions` become `platform_permission_denied`. If the foundation maps fewer reasons, report that to the foundation builder; do not remap in GSC code.

## 4. Tools

Common to all reads: `kind: "read"`, risk `read`, declared with `gscRead` (scope notes come from the foundation: `webmasters.readonly` or `webmasters`). `account_id` is the site account. Errors common to all: 401 → `auth_expired` (reconnect Search Console); 403 permission → `platform_permission_denied` ("the connected Google user has no access to <site> in Search Console, or lost it"); 403/429 quota → `quota_exceeded` (retryable, with retry-after when sent; message mentions F27 load quota: "wait 15 minutes"); 404 → `not_found`; 400 → `invalid_argument` with Google's message (redacted by `toToolError`); 5xx → `transient`. Analytics tools use `searchAnalytics(..., { partial: true })` and always report `truncated`.

### 4.1 `list_gsc_sites`
- **Kind / risk**: read.
- **Endpoint**: `GET /webmasters/v3/sites` (F32) through the connection of the named site.
- **Input**: `{ account_id, limit: int 1..1000 default 200 }`.
- **Output**:
  ```ts
  { sites: { site_url: string, property_type: "domain" | "url_prefix", permission_level: string, verified: boolean, is_this_account: boolean }[],
    returned: number, truncated: boolean,
    note: string } // "Sites listed here are those the connected Google user can see. Each verified one is a separate account in list_accounts after the connection is refreshed."
  ```
  `verified = permission_level !== "siteUnverifiedUser"`. Sorted by `site_url`.
- **Caps**: no API pagination; slice to `limit`, `truncated = all.length > limit`.
- **Errors**: common.
- **Open**: whether the tool should say which listed sites are already connected accounts (needs db; see Q1).

### 4.2 `get_search_performance`
- **Endpoint**: `POST …/searchAnalytics/query` (F1), plus one totals query and, for presets, the date probe.
- **Input** (`z.object(...).superRefine(validate)`):
  ```ts
  { account_id,
    ...periodFields,
    dimensions: z.array(z.enum(DIMENSIONS)).max(7).default([]),           // unique (refine)
    type: z.enum(SEARCH_TYPES).default("web"),
    filters: z.array(filterSchema).max(10).default([]),                    // one "and" group
    aggregation_type: z.enum(AGGREGATIONS).default("auto"),
    data_state: z.enum(DATA_STATES).default("final"),
    limit: z.number().int().min(1).max(5000).default(100),
    start_row: z.number().int().min(0).max(50_000).default(0) }
  ```
  Validation (each a clear `invalid_argument`, before any call):
  1. `searchAppearance` in `dimensions` → it must be the only dimension (F19). Point to `get_search_appearance`.
  2. `hour` in `dimensions` → `data_state` must be `hourly_all` (F14; safe reading of "should").
  3. `type = discover` → no `query` dimension or filter (F22). Position is reported null-able anyway.
  4. `byProperty` with page dimension or page filter → refuse (F12). `byProperty` with `discover`/`googleNews` → refuse (F12).
  5. `byNewsShowcasePanel` → requires a filter `searchAppearance equals NEWS_SHOWCASE`, type `discover|googleNews`, no page dimension/filter, no other searchAppearance filter (F12).
  6. Dates per §2.1.
- **Calls**:
  1. `resolvePeriod` (preset only: 1 probe query).
  2. Main: `searchAnalytics(body, { maxRows: limit, startRow: start_row, partial: true })`.
  3. Totals: same body with `dimensions: []` (and same filters/type/aggregation/dataState), `maxRows: 1`. Skipped when `dimensions` is empty (the main row is the total). When the totals row is absent: totals all zero, `ctr`/`position` null.
- **Output**:
  ```ts
  { site_url, type, data_state, period: Period,
    dimensions: string[],
    rows: (Record<dimension, string> & Metrics)[],        // keys flattened into named fields, in Google's order (F16)
    totals: Metrics.describe("Whole property for the filters, including anonymized queries unless a filter is set"),
    response_aggregation_type: string | null,
    first_incomplete_date: string | null, first_incomplete_hour: string | null,
    returned, start_row, truncated,
    notes: string[] }
  ```
  `notes` always includes: rows can sum to less than totals (F23); Google returns at most 50,000 rows per day per search type and may drop rows when grouping by page or query (F18); dates are Pacific Time. Adds the Discover note when `type=discover`, the fresh-data note when `data_state≠final`.
- **Row caps**: output ≤ 5,000 rows per call; continuation by `start_row` (the response says `next_start_row = start_row + returned` when truncated).
- **Time zone**: all dates PT; `period.time_zone` always `America/Los_Angeles`.

### 4.3 `get_top_queries`
- Shortcut over 4.2 with `dimensions: ["query"]`, `type` limited to `web | image | video | news | googleNews` (Discover has no queries, F22).
- **Input**: `{ account_id, ...periodFields, type default "web", page_filter?: string(1..4096) (page contains), country?: alpha-3, device?: DESKTOP|MOBILE|TABLET, query_contains?: string(1..4096), exclude_query_regex?: string(1..4096), limit: int 1..1000 default 25 }`.
- **Output**: `{ site_url, type, period, queries: { query, ...Metrics }[], totals, returned, truncated, notes }`. Sorted by clicks desc (F16, Google's order).
- Totals query as in 4.2 (anonymized queries note applies; if `query_contains`/regex set, note that totals omit anonymized queries).

### 4.4 `get_top_pages`
- Shortcut with `dimensions: ["page"]`, all types allowed.
- **Input**: `{ account_id, ...periodFields, type default "web", page_contains?, country?, device?, query_contains? (refused for discover), limit 1..1000 default 25 }`.
- **Output**: `{ site_url, type, period, pages: { page, ...Metrics }[], totals, returned, truncated, notes }`.
- `aggregation_type` stays `auto` (F12; page grouping cannot use byProperty). Note that page-grouped CTR and position are computed differently from property totals (all-your-data).

### 4.5 `compare_search_periods`
- **Input**:
  ```ts
  { account_id, dimension: z.enum(["query", "page"]),
    type: z.enum(SEARCH_TYPES).default("web"),               // query + discover refused
    period: z.enum(PERIODS).default("last_28_days"),         // the current period (ends on latest data day)
    start_date?, end_date?,                                   // explicit current period
    previous_start_date?, previous_end_date?,                 // default: same length immediately before
    filters: z.array(filterSchema).max(10).default([]),
    scan_limit: int 1000..25_000 default 5000,                // rows read per period
    min_impressions: int 0..1e6 default 10,                   // ignore tiny rows for movers
    limit: int 1..200 default 25 }                            // per output list
  ```
  Refuse when the previous period overlaps or follows the current one.
- **Calls**: probe (preset), two main queries (`maxRows: scan_limit, partial: true`), two totals queries. 4–5 queries.
- **Join**: map by key. For a key missing in one period: if that period was **not** truncated → the missing side is 0 clicks/impressions, position null (`status: "new"` or `"lost"`); if it **was** truncated → value unknown, `status: "beyond_cap"`, deltas null. Never treat "past the cap" as zero (anti-goal).
- **Output**:
  ```ts
  { site_url, type, dimension,
    current: Period & { totals: Metrics, rows_read: number, truncated: boolean },
    previous: Period & { totals: Metrics, rows_read: number, truncated: boolean },
    periods_equal_length: boolean,
    totals_change: { clicks, impressions, ctr: number|null, position: number|null },
    risers: Mover[], fallers: Mover[], new: Mover[], lost: Mover[],
    beyond_cap: number,                       // keys whose other side is unknown
    notes: string[] }
  Mover = { key, clicks_current, clicks_previous, clicks_change, impressions_current, impressions_previous, impressions_change,
            position_current: number|null, position_previous: number|null, position_change: number|null, status: "both"|"new"|"lost"|"beyond_cap" }
  ```
  `position_change = current − previous` (negative = moved up); `notes` say so. Risers/fallers sorted by `clicks_change` then `impressions_change`, keys with `max(impressions) < min_impressions` dropped. Notes: only the top `scan_limit` keys by clicks in each period were compared; a period ending later than the latest data day is flagged (explicit dates only).

### 4.6 `get_search_appearance`
- **Input**: `{ account_id, ...periodFields, type: z.enum(["web","image","video","news","discover","googleNews"]).default("web"), appearance?: z.string().regex(/^[A-Z0-9_]{2,64}$/), breakdown: z.enum(["none","query","page"]).default("none"), limit 1..1000 default 50 }`.
- **Calls**: always `dimensions: ["searchAppearance"]` alone (F19), `maxRows: 200, partial: true`. With `appearance` and `breakdown ≠ none`: a second query `dimensions: [breakdown]`, filter `searchAppearance equals appearance` (F19's documented two-step method). `breakdown=query` + discover refused.
- **Output**: `{ site_url, type, period, appearances: { appearance: string, label: string | null, ...Metrics }[], breakdown: null | { appearance, dimension, rows: ({ key } & Metrics)[], truncated }, returned, truncated, notes }`. `label` from the F20 table (null for unknown values; the raw value is always passed through, never enum-validated in output). Notes: search-appearance data is aggregated by page (answer/17011259), FAQ is deprecated (F21).

### 4.7 `inspect_url`
- **Endpoint**: `POST https://searchconsole.googleapis.com/v1/urlInspection/index:inspect` (F41).
- **Input**: `{ account_id, url: z.string().url().max(2048) (http/https), language_code: z.string().regex(/^[A-Za-z]{2,3}(-[A-Za-z0-9]{2,8}){0,3}$/).optional() }`.
  Refuse (no API call, no quota spent) when `!withinProperty(siteUrl, url)` (F41 "must fall under the property").
- **Output** (enums are passed through as strings; known values explained):
  ```ts
  { url, site_url, inspection_result_link: string|null,
    verdict: string|null, coverage_state: string|null, robots_txt_state: string|null, indexing_state: string|null,
    page_fetch_state: string|null, last_crawl_time: string|null, crawled_as: string|null,
    google_canonical: string|null, user_canonical: string|null,
    canonical_mismatch: boolean|null,              // both present and different
    sitemaps: string[], referring_urls: string[], referring_urls_truncated: boolean,  // cap 20 each
    rich_results: null | { verdict: string|null, items: { type: string|null, name: string|null, issues: { message: string|null, severity: string|null }[] }[] },  // cap 50 items
    amp: null | { amp_url, verdict, index_status_verdict, indexing_state, robots_txt_state, page_fetch_state, last_crawl_time, issues: {message, severity}[] },
    explanation: string[],
    notes: string[] }   // "Shows Google's indexed version, not a live test." "Each call uses 1 of 2,000 inspections per property per day."
  ```
  `explanation` maps F44–F47 and F49 values to plain sentences, e.g. `NEUTRAL` → "Excluded from the index (see coverage state)"; `BLOCKED_BY_META_TAG` → "A noindex meta tag blocks indexing"; `SOFT_404` → "Google treated the page as a soft 404"; unknown value → "Google returned <X>, which this server does not recognise". `mobileUsabilityResult` is deprecated (F42): not read, not returned.
- **Errors**: quota (`429`/`403 quotaExceeded`/`RESOURCE_EXHAUSTED`) → `quota_exceeded` with message "Search Console allows 2,000 URL inspections per property per day and 600 per minute; this property has hit one of them. Retry later (the daily limit resets daily; Google does not say at what hour)." 400 "not part of this property" → `invalid_argument`.
- **Caps**: one URL per call (no batch; protects the 2,000/day quota).

### 4.8 `list_sitemaps`
- **Endpoint**: `GET …/sites/{siteUrl}/sitemaps[?sitemapIndex=]` (F38).
- **Input**: `{ account_id, sitemap_index?: z.string().url().max(2048), limit: int 1..500 default 100 }`.
- **Output**:
  ```ts
  { site_url, sitemap_index: string|null,
    sitemaps: { path, type: string|null, is_index: boolean|null, is_pending: boolean|null,
                last_submitted: string|null, last_downloaded: string|null,
                errors: number|null, warnings: number|null,
                contents: { type: string|null, submitted: number|null }[] }[],
    returned, truncated, notes }
  ```
  `contents[].indexed` is deprecated (F40) and never read. Notes: errors are problems with the sitemap itself that block processing; warnings are mostly non-critical URL issues (F40). Sorted by `path`.
- **Caps**: no API pagination; slice to `limit`, `truncated`.

### 4.9 `submit_sitemap` (write, risk `write`)
- **Endpoint**: `PUT …/sitemaps/{feedpath}` (F39), scope `webmasters` (F3).
- **Input**: `{ account_id, sitemap_url: z.string().url().max(2048) (http/https, no fragment) }`.
- **plan()** (read-only):
  1. `withinProperty(siteUrl, sitemap_url)` else `invalid_argument` (safe choice for U5).
  2. `getSite()`; `siteRestrictedUser` → `platform_permission_denied` ("restricted users cannot submit sitemaps", F51); `siteUnverifiedUser` → `platform_permission_denied` ("verify ownership first").
  3. `existing = getSitemap(sitemap_url)`.
  - snapshot: `{ site_url, permission_level, existing: existing ? { last_submitted: existing.lastSubmitted ?? null } : null }` (only fields that change by a person's action; never `isPending`, `lastDownloaded`, `errors`, which Google changes by itself and would cause false conflicts).
  - summary: new → `Submit sitemap <url> to Search Console property <site>. Google reads it later; this does not request indexing of any page.` Existing → `Resubmit sitemap <url> to <site> (last submitted <date>, <n> URLs, <e> errors). Google will read it again later.`
- **execute()**: `submitSitemap(url)`; read back `getSitemap(url)`; absent → `unknown_outcome` ("Google accepted the request but the sitemap does not read back"). Output `{ site_url, sitemap_url, resubmitted: boolean, last_submitted: string|null, is_pending: boolean|null }`.
- **verify()**: `getSitemap`: absent → `not_applied`; present and (`snapshot.existing` null or `lastSubmitted` changed) → `applied`; present with unchanged `lastSubmitted` → `indeterminate` ("a resubmission cannot be told apart from no change").
- **Drift / idempotency**: the pipeline re-plans and compares snapshots; a sitemap someone else submitted or resubmitted meanwhile → `conflict`. PUT is idempotent on Google's side but is still sent once and never retried.

### 4.10 `delete_sitemap` (write, risk `destructive`)
- **Endpoint**: `DELETE …/sitemaps/{feedpath}` (F39).
- **Input**: `{ account_id, sitemap_url: z.string().url().max(2048) }`.
- **plan()**: `listSitemaps()` (top level); the exact `path` must be there, else `not_found` ("not a sitemap submitted for this property; sitemaps listed inside an index cannot be removed one by one here"). Permission check as 4.9 (U10 safe choice: refuse restricted and unverified).
  - snapshot: `{ site_url, path, last_submitted }`.
  - summary: `Remove sitemap <url> from Search Console property <site> (type <type>, <n> URLs submitted, last read <lastDownloaded>, <e> errors, <w> warnings). The file on the website is not changed. Google's API docs do not say whether Google stops reading the URLs it lists.` If `isSitemapsIndex`: add "This is a sitemap index; the sitemaps inside it are removed from this list too" only if confirmed, otherwise "it is a sitemap index covering other sitemaps" (do not claim the cascade).
- **execute()**: `deleteSitemap(url)`; read back `getSitemap(url)`: null → output `{ site_url, sitemap_url, removed: true }`; still present → `unknown_outcome`.
- **verify()**: `getSitemap` null → `applied`; present → `not_applied`.
- **Drift**: resubmitted meanwhile (`last_submitted` changed) → `conflict`; already gone → re-plan throws `not_found` (no mutation).

### 4.11 `add_gsc_site` (write, risk `write`)
- **Naming**: `account_id` is **any site account of the same GSC connection** (design §6); it only selects the Google user. If the connection has no site yet, the Connections page adds it instead (design).
- **Endpoint**: `PUT /webmasters/v3/sites/{siteUrl}` (F34).
- **Input**: `{ account_id, site_url: siteUrlSchema }` (`sc-domain:example.com` or `https://www.example.com/` with trailing slash, F37).
- **plan()**: `findSite(site_url)`: present (any level) → `invalid_argument` ("already in this user's Search Console with permission <level>"; U1 safe choice). snapshot `{ site_url, present: false }`. summary: `Add <site_url> to the Search Console of the Google user connected through <naming site>. Ownership is not verified by this: until it is verified in Search Console (DNS record for a domain property; HTML file, tag, DNS, Analytics or Tag Manager for a URL prefix), the property shows as unverified and has no data. After verifying, refresh Search Console on the Connections page to use it here.` (Verification method list: from knowledge — keep the sentence generic, "verify ownership in Search Console", unless the builder confirms the methods page; see Q6.)
- **execute()**: `addSite(site_url)`; read back `findSite(site_url)`; absent → `unknown_outcome`. Output `{ site_url, permission_level: string, verified: boolean, next_steps: string }`.
- **verify()**: `findSite` present → `applied`; absent → `not_applied`.
- **Drift**: site appears between plan and execute → re-plan throws (conflict path). Never retried.
- **Tenancy**: the new site is not an account until discovery runs again (Q2).

### 4.12 `remove_gsc_site` (write, risk `destructive`)
- **Naming**: `account_id` is the site to remove. Input also requires `confirm_site_url` equal to that account's external id, exactly (typo guard for a destructive call).
- **Endpoint**: `DELETE /webmasters/v3/sites/{siteUrl}` (F35).
- **Input**: `{ account_id, confirm_site_url: z.string().min(1).max(2048) }`.
- **plan()**: mismatch → `invalid_argument`. `getSite()` → permission level (404 → `not_found`). snapshot `{ site_url, permission_level }`. summary: `Remove <site> from the connected Google user's list of Search Console properties (their permission: <level>). Google's API docs do not say what this does to the property's other users, its verification or its data; check in Search Console first. Its sitemaps and data stop being reachable through this connection.`
- **execute()**: `deleteSite()`; read back `findSite(siteUrl)`; absent → `{ site_url, removed: true, note: "Refresh Search Console on the Connections page to drop this account." }`; present → `unknown_outcome`.
- **verify()**: absent → `applied`; present → `not_applied`.
- **Drift**: permission level changed → `conflict`.
